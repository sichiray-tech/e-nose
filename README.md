# e-nose
6-channel MOX electronic nose sensor kit with PC software to visualize, map, and train custom odor fingerprints using machine learning. 

## Overview

The electronic nose sensor accurately distinguishes a wide range of aromas and odors — a professional-grade electronic nose you can buy with confidence for perfumery, food, daily chemicals, and factory inspection.

Manual smelling is inaccurate and harmful to your nose. This sensor quantifies odors directly, displays real-time waveforms through PC software, and generates a unique data profile for every odor.

## Hardware & Software Usage

• Adapter: Plug into the computer's USB port.

• Sensor: Powered via the Type-C port using a 5V power adapter.

• After powering on, let the sensor sit still in the environment for 1–2 minutes and wait until it stabilizes before measuring.

• It is normal for the sensor to heat up during operation — this is caused by the working principle of the sensor module itself.
